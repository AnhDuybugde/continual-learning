# DPST-Core report

Status: **DPST-Core smoke PASS; full benchmark blocked by protocol stage**.

DPST-Core currently contains only the specified adaptive learning-rate (`eta`) and replay-weight (`lambda`) controls around the shared TCN + AdamW + reservoir replay path. It does not include a neural controller, drift detector, relevance-aware replay, or NatSR/Fisher machinery.

Smoke configuration: ETTh1, target `OT`, seed `7`, `L=60`, `H=1`, train/validation/online `20%/5%/75%`, LR candidates `{1e-3, 3e-4}`, selected `1e-3`, reservoir capacity `500`, replay batch `8`. Data SHA-256 is in `artifacts/smoke_etth1/data_manifest.json`.

DPST trajectories (`eta`, `lambda`, `alignment`, `forget_score`) are logged per resolved sample in `artifacts/smoke_etth1/DPST/online_metrics.jsonl`; the checkpoint is `artifacts/smoke_etth1/DPST/checkpoint.pt`. The deterministic fixed-controller equivalence test now compares prediction/loss diagnostics, parameters, optimizer state, replay indices, and replay state over four updates with `rtol=1e-6`, `atol=1e-8`; it passes on CPU. Trajectory equality in tolerance is the gate; bitwise equality is not required.

No full benchmark or external baseline claim is made. The adapter milestone did not alter DPST-Core; the complete suite is 13/13 PASS and the ETTh1 smoke execution is 1/1 PASS. Runtime logging includes wall-clock, prediction and update time; CPU peak RSS is stored in each `timing.json`. CUDA memory is recorded when a CUDA run is used. Plots are generated by `scripts/generate_report_plots.py` from saved JSONL artifacts.

## Three-seed ablation milestone

ETTh1 H=1 was run with seeds 0, 1, and 2 using the common causal protocol and
1,999 resolved samples per run. ER mean MAE/MSE was `0.089916/0.014234`;
DPST-eta `0.091432/0.014659`; DPST-lambda `0.089082/0.013976`; DPST-full
`0.089573/0.014052`; DER++ `0.089703/0.014161`. DPST-full beats ER and DER++
on the aggregate metrics, but eta-only is worse than ER across all seeds, so
the evidence is pilot-level and does not show independent benefit from both
components. H=24 smoke (seed 0, 176 resolved samples) was finite for ER, DPST,
and DER++; DPST scored `0.306701/0.152023` MAE/MSE.

Artifacts are under `artifacts/dpst_milestone/`; these runs are engineering
preflight evidence and are excluded from confirmatory statistics.

Reproduction commands:

```text
python scripts/run_dpst_milestone.py --device cuda --prefix 2000 --h24-prefix 200 --seeds 0 1 2
python scripts/run_derpp_three_seeds.py --device cuda --prefix 2000 --seeds 0 1 2
```
## Fixed replay-weight comparison

The follow-up ETTh1 H=1 pilot compared λ ∈ {0, 0.25, 0.5, 0.75, 1.0} over
seeds 0, 1, and 2 using the same split, scaler, validation-only LR selection,
causal queue, and 1,999 resolved samples.

| λ | MAE mean ± std | MSE mean ± std |
|---:|---:|---:|
| 0.00 | 0.097534 ± 0.004224 | 0.016304 ± 0.001400 |
| 0.25 | 0.091718 ± 0.003259 | 0.014706 ± 0.001032 |
| 0.50 | 0.089916 ± 0.002777 | 0.014234 ± 0.000926 |
| 0.75 | 0.089168 ± 0.002565 | 0.014021 ± 0.000877 |
| 1.00 | **0.089062 ± 0.002591** | **0.013963 ± 0.000862** |

DPST-full was MAE `0.089573` and MSE `0.014052`; it therefore did not beat
fixed λ=1.0. Artifact: `artifacts/dpst_milestone/fixed_lambda/results.json`.
